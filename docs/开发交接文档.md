## 1. 项目是什么（一句话）

InsightFlow 是一个**离线优先**的本地数据洞察流水线：每天自动扫描本地 Excel/CSV → 识别字段 → 清洗 → 生成分析计划 → 计算指标 → 渲染单文件离线 HTML 报告。当前版本 **v1.0.2**。

阶段 0 新增了一个**与主流程完全隔离**的 LLM 模块（`src/insightflow/llm/`），用 DeepSeek 大模型做「语义理解 + 分析规划」，已通过真实 API 调用验证，判定 **Go**。

## 3. 主流程架构（8 步，`pipeline.execute()`）

`discovery → read → schema/日期筛选 → (幂等判断) → clean → plan → analyze → artifacts/report`

关键工程机制（已存在，勿破坏）：

- **并发锁**：`state/.pipeline.lock`，防止定时任务与手动运行并发写坏报告。
- **幂等**：数据指纹一致且报告存在时跳过（`--force` 可强制重算）。
- **失败不静默**：任何异常都转成结构化 `RunRecord`，写入 `logs/runs.jsonl`。
- **确定性**：核心指标由本地规则/计算产出，不依赖网络，结果可复现。
- **单文件报告**：CSS/JS/ECharts 全部内联，无 CDN、无 fetch、无后端。

## 4. LLM 模块结构（本次交接重点）

路径：`src/insightflow/llm/`

| 文件 | 职责 |
|---|---|
| `payloads.py` | 载荷最小化（只取字段结构 + 前 10 行）+ 敏感信息脱敏 + 行数断言 |
| `contracts.py` | 版本化输出契约：拒绝业务数字、图表数据槽必须为空、非法 role 即失败 |
| `client.py` | 纯标准库（`urllib`）DeepSeek 客户端：重试/超时/成本熔断；**唯一允许用 urllib 的文件** |
| `evaluate.py` | 字段角色准确率、编造数字检测、多次运行汇总 |
| `prompts/analysis_plan_v1.md` | 系统提示词（版本号 `analysis_plan_v1`） |
| `__main__.py` | CLI：`python -m insightflow.llm payload|plan` |

**隔离是硬约束（有测试断言）**：

- 核心与 GUI 代码**不得** `import insightflow.llm`。
- LLM 目前是独立 PoC，**尚未接入主流程**。
- `client.py` 是全仓库唯一允许使用 `urllib` 的文件。

## 5. 本次会话的变更清单（★禁止回退，逐条核对）

### 5.1 `src/insightflow/llm/client.py`（3 处）

1. **修复端点路径缺陷（真实 bug）**：`_endpoint()` 原本只返回 `base_url`，漏拼 `CHAT_PATH`，真实请求会打到根路径而非 `/chat/completions`。
   - 现实现：`return self.config.base_url.rstrip("/") + CHAT_PATH`
   - 根因：单测替换了 transport，请求没经过真实 URL 构造，mock 全绿也发现不了。
2. **关闭 Flash 默认思考模式**：请求体新增 `"thinking": {"type": "disabled"}`。Flash 默认开思考会产生额外推理 token；规划任务无需推理，关闭以控成本、降延迟。
3. **重构 `.env` 候选路径为可替换函数**：新增模块级 `dotenv_candidates()`，`from_env()` 改为遍历它（原先是内联硬编码两个路径）。生产行为不变，仅为让测试可隔离。

### 5.2 `tests/test_llm_poc.py`（2 处，测试隔离修复）

- `test_dotenv_is_loaded_when_environment_is_absent`、`test_real_environment_overrides_dotenv` 两个测试，用 `patch("insightflow.llm.client.dotenv_candidates", return_value=[tmp / ".env"])` 隔离，使其只加载临时目录配置，不被项目根真实 `.env` 污染。
- 背景：项目根一旦存在 `.env`，旧测试会被其覆盖而失败。

### 5.3 新建 `.env`（项目根，含真实密钥，已被 `.gitignore` 忽略）

## 9. 红线（不可违背的设计约束）

1. **离线优先**：核心流水线不得引入网络调用；联网能力只能存在于 `llm/client.py`。
2. **LLM 只做规划，不产业务数字**：任何合计/均值/占比/同环比/行数等数值必须由本地 `execute()` 计算；契约层对 metric 类键带数字直接判失败。
3. **数据最小化 + 脱敏**：上云只传字段结构 + 前 10 行，敏感字段先掩码；完整明细不出本机。
4. **配置化**：模型名、单价、密钥只能来自环境变量/`.env`，代码不得硬编码未经验证的模型串或单价。
5. **隔离断言不可删**：核心/GUI 不得 import `insightflow.llm`；`client.py` 是唯一可用 `urllib` 的文件。
6. **契约失败不做自由文本兜底**：非 JSON、缺字段、非法 role、非空数据槽一律失败。
7. **密钥安全**：`.env` 不得入库；禁止在日志、报告、提交信息中出现完整 `sk-` 密钥。
