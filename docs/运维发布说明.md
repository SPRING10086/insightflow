# InsightFlow 运维发布说明（v1.0.2）

> 面向运维/部署。操作员请看包内 `使用说明.txt`。全程离线是设计行为，不是故障。

## ① 安装部署

| 动作 | 判定标准 |
|---|---|
| 解压 `dist/InsightFlow/`（约 **207 MB**）到固定目录 | 见 `app/`、`python/`、`启动操作端.vbs`、`启动操作端(排障).bat`、`使用说明.txt` |
| 装 **VC++ 2015-2022 运行库**（干净 Windows 常缺） | 双击能出窗口；报缺 DLL / 0xc000007b 先装运行库 |
| 双击 **`启动操作端.vbs`**（无黑框） | 出现「InsightFlow 操作端」，顶部徽标「锁定环境」；起不来改用 `启动操作端(排障).bat` |
| 首次遇 SmartScreen | 「更多信息」→「仍要运行」（未签名，分发前补签名） |
| 弹「环境不可信」 | 解释器/依赖偏离锁定版本：改用包内 `python\python.exe`，勿绕过 |

随包自带、无需另装也无需联网：Python **3.10.4**、pandas **2.3.3**、numpy **2.2.6**、openpyxl **3.1.5**、xlrd **2.0.2**。

## ② 首跑确认

1. **放数据**：「放入待分析数据」或「选择文件…」→「刷新清单」。**判定**：状态「可读取」；不支持类型标注「不支持的类型」。
2. **日期**：目标日期默认昨天；口径默认「月/日/年（默认）」，不改即保持。
3. **运行**：「开始分析」。**判定三条同时满足**：① 底部「最近一次运行：成功」；②「获取清洗后数据」「获取数据报表」由灰变亮；③ `app/output/<日期>/` 有 `cleaned_data.csv`、`InsightFlow_*.html`、`metrics.json`。
4. **无人值守**：「管理员设置」→「每日触发时间」（默认 **09:30**）→「安装 / 更新任务」。**判定**：底部「定时任务：已安装（每天 09:30，下次 …）」。

## ③ 日常巡检

| 项目 | 动作与判定 |
|---|---|
| 运行 | 「历史记录」状态均「成功」；失败看原因，可「重跑所选」；产物在 `app/output/<日期>/` |
| 质量 | 五类告警：文件读取失败 / 重复行去重 / 缺失值填补 / 离群值标记 / 日期存在歧义。≥90 优秀、80 良好、60 需关注、<60 较差；**<80 或有坏文件/填补/离群时须人工复核，估算值不得当实测引用** |
| 日志 | `app/logs/insightflow.log`；运行记录 `runs.jsonl`、`latest_run.json` |
| 调度 | 「管理员设置」看已安装与下次时间；失败在宽限 **180 分钟**内每 **5 分钟**自动重试 |
| 对账 | `python scripts/reconcile.py output/<日期>` → 全 **PASS**（演示数据 11 项）、退出码 0；建议每周或换数据源后执行 |

## ④ 故障自检（现象 → 自查 → 判定）

| 现象 | 自查动作 | 判定 |
|---|---|---|
| 双击无窗口 / 启动即退 | 用排障 bat，看 `insightflow.log` 与 `%TEMP%\insightflow_gui_stderr.log`；报缺 DLL / 0xc000007b 则装 VC++ 2015-2022 后重启 | 能看到具体报错并修复 |
| 「已有任务在执行」 | 看 `app/state/.pipeline.lock` 修改时间，确认无真实进程 | 锁 **150 分钟**后自动失效，**勿强删** |
| 运行失败 | 历史记录原因 + 日志 | 5 分钟内自动重试（宽限 180 分钟）；持续失败再人工 |
| 「环境不可信」 | 顶部「解释器」是否指向包内 `python\python.exe` | 指向包内即恢复 |
| 数据告警 | 按质量区提示处理 | 坏文件只影响自身；填补/离群复核后再引用 |
| 报告/文件夹打不开 | 「更多产物」或直接看 `app/output/<日期>/` | 产物在即可手动打开 |

## ⑤ LLM 增强（实验，默认关闭）

- **入口**：操作端右上角「LLM 增强（实验）」→ 勾选总开关与四个功能（语义识别 / 分析计划 / 受控执行 / 智能解读）→「保存」。
  无需改 JSON、无需命令行；保存后**下次运行**生效。
- **默认关闭**：关闭时报告、产物与规则结果完全一致，不产生任何 LLM 文件、不联网。
- **成本护栏（只读）**：单表 ¥5 / 整批 ¥20；结果区显示本次成本、四段来源、对账结论与降级原因。
- **密钥**：由运维在 `app/.env` 配置 `DEEPSEEK_API_KEY`（不写入 `config.json`、不进入分发包）；
  界面只显示「已配置 / 未配置」，不回显 Key。
- **失败即降级**：任一环节异常都会回退规则结果，运行仍显示「成功」；`run_record.json` 的
  `metadata.llm_stats` 记录重试/降级/成本，详见 `docs/llm-stage5-notes.md`。
- **巡检**：`python scripts/llm_stats.py --root app` 看不闭合率/降级率/成本；
  发布前跑 `scripts/verify_release.ps1`（清单见 `docs/release-checklist-llm.md`）。
- **数据边界**：开启后仅把「字段结构 + 前 10 行脱敏样本 + 字段/计划键名」发往配置的 API；默认关闭时无出站连接。

**发布前置（正式对外分发前）：代码签名、干净虚拟机安装/启动/VC++ 依赖确认。**
